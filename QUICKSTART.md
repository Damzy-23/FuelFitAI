# ⚡ FuelFit AI - Quick Start (30 seconds)

## Install & Run

```bash
# 1. Install everything
npm run install-all

# 2. Start the app
npm run dev
```

That's it! 🎉

- Open http://localhost:3000
- Backend runs on http://localhost:3030

## Optional: Add AI Features

Create `server/.env`:
```
OPENAI_API_KEY=sk-your-key-here
```

**Note:** Works perfectly without it! Uses smart defaults.

## Demo Flow

1. Select "Burger" from presets
2. Choose "🏃 Running"
3. Select "Fat Loss" goal
4. Click "Analyze Meal"
5. See: Workout cost, FuelScore, AI explanation
